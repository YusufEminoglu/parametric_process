about=Parametric Process lets you describe a design as rules and let the computer search the options. Build reusable node-based workflows on block and parcel layers, then run NSGA-II evolutionary optimisation across density, daylight, carbon and urban-quality objectives.
    Explore the trade-offs on the Pareto front and in a parallel-coordinates plot, preview each candidate in 3D as it evolves, and write the solutions you approve back to QGIS as ordinary vector layers. Each building is scored against its own district context rather than one city-wide average.
    Manual: https://geophilo.com/parametric_process/manual.html

changelog=
    3.3.1 - Hub listing text rewritten; author Geophilo; university affiliation removed; documentation links use the standard geophilo.com pages (manual.html, guide/); manual HTML no longer ships in the plugin package.
    3.3.0 - Model and solver corrections: the wind alignment term rewarded the blocking orientation; the composite score rewarded breaking the FAR; floor height was never mutated; SPEA2 distances depended on objective units and its output carried rank 0; MOEA/D listed one design several times; genotype repair now covers FAR. District Coupling now computes each building from its real neighbours instead of writing one average to every feature. Evaluators no longer fail on layers without genotype fields. Shape-grammar and PPUD plots are clipped to their block. Valid CityJSON 1.1 export. The local studio server refuses requests from other web sites.
    3.2.0 - NSGA-III now performs real reference-point niching (Deb & Jain 2014); it previously behaved as NSGA-II. MOEA/D compares range-normalised objectives. Roof sol-air temperature responds to the design instead of being a constant.
    3.1.1 - Upgraded official plugin icon to high-end tactile 3D brand identity with circular teal pedestal; synchronized documentation, repository and issue tracker endpoints to GeoPhilo and GitLab.
    Parametric Process 0.1.0 - Initial Release: Parametric generative urban design suite with NSGA-II multi-objective evolutionary solver, 3D Three.js cockpit, Parallel Coordinate Plot (PCP), 2D Pareto Front Scatter plot, Diamond/Radar phenotype charts, generation convergence graph, real-time phenotype 3D preview, and 2-way QGIS vector layer sync.
